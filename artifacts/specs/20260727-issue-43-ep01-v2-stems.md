## 4. Scope and deliverables

**A. `episodes/cast.json` gains the host role.** Daniel, `onwK4e9ZLuTAKqWW03F9`, vendor
`elevenlabs`, source `premade`, plus a field marking it **interim** and naming what replaces
it (the maintainer's own narration). Same field set as the existing entry; extend the
`pipeline/core/cast.py` loader only if it needs it, and keep its `CastError` behaviour.

**B. A transcript parser** producing an ordered list of turns — index, speaker, text —
from `episodes/ToldStraight-Ep01/transcript.md`. It must be **exact**: 54 turns, 27/27,
and the character counts above. If your parse disagrees with §2, **stop and report** — a
silent parse drift would misquote the spend.

**C. A render path, dry-run by default.** Reuse the `screentest` pattern
(`pipeline/core/screentest.py`) — do not reinvent it:

- Default is a dry-run printing every planned turn, the per-speaker and total character
  counts, the credit quote, and the current ledger. **Spends nothing.**
- Rendering requires an explicit `--confirm-spend`. The pre-flight gate still refuses any
  batch over the ~2,000-credit self-serve threshold; this pass exceeds it, so the gate must
  take an explicit, **auditable** override naming the authorised ceiling (5,600) — never a
  silent bypass, and never a lowered threshold. A future batch with no authorisation must
  still hard-stop after this work lands.
- **Resumability matters here.** The digest-manifest cache must mean a re-run after a
  mid-batch failure re-bills nothing for turns already rendered. Prove it: re-run the
  render after completion and show that it spends zero.
- One request per turn (every turn is inside the v3 cap; never concatenate turns).
- Stems land under `output/` with self-describing names — turn index zero-padded so a
  lexical sort is playback order — and a sibling `manifest.json` carrying turn index,
  speaker, `voice_id`, chars, `credits_est`, `credits_measured`, and the parameter digest.

**D. An assembly step** concatenating stems in turn order into a single 192 kbps master via
`ffmpeg`, with a configurable inter-turn gap (default something conversational, ~350 ms;
state the value chosen). It must work from stems alone, so it can be re-run after a host
swap without touching the guest track. Assembly spends **no credits** and must be
demonstrable — build it so it can be proven with silent or synthetic input rather than only
after a real render.

**E. Speaker labels** across `transcript.md`, `.txt`, and `.html`: `EXPERT (Emma)` →
`EXPERT (Owen)` (27 each) and `HOST (bm_fable)` → `HOST`. Also the byline on line 3 of the
`.md`. Verify the `.html` structure survives — it is a deliverable, not a scratch file.
**Do not touch `transcript.vtt` or `captions-autosync.txt` unless they carry the same
labels; check, and report what you found either way.**

**F. Tests** — network fully stubbed, **zero credits**, covering the parse (54/27/27 and
the character counts), the quote arithmetic, the manifest schema, turn ordering, and that
the dry-run never calls `/v1/text-to-speech`.

**G. Docs** — `ROADMAP.md` § M4; `CHANGELOG.md` entry, plus § Findings for anything learned
that the diff does not show.

## 7. Risk

**The expensive mistake is spending before the plan is reviewed** — hence §0.1 and the
negative test in §5. 5,074 credits is 4% of the month and a bad turn boundary found after a
monolithic render would cost it twice; per-turn stems exist to make a mistake cost ~40
credits instead.

**The subtle mistake is a parse that drifts from §2** and quietly misquotes the spend. That
is why the counts are acceptance criteria rather than incidental output.
