# ADR 0004 — One Professional Voice Clone slot

- **Number:** 0004
- **Title:** One Professional Voice Clone slot
- **Status:** accepted
- **Date:** Not recorded in the source entry.
- **Source:** `ROADMAP.md` § "Decisions and what they constrain" (entry migrated by #62).

## Context

`professional_voice_limit: 1`. Instant cloning is unlimited within 30 slots and costs
no credits. Spending the single PVC slot is effectively irreversible, which is why
`AGENTS.md` § "Hold for the maintainer" gates it.

## Decision

Hold the Professional Voice Clone slot unless cloned-Jared becomes a primary narrator.

## Consequences

**Constrains M4:** record host lines live, build an **Instant** clone from those takes
as a patch tool for one-line fixes. See
[`docs/voice-capture.md`](../voice-capture.md).

## Reversal condition

Not recorded at decision time.
